このフォルダに動画を置くだけで、LPが自動的にシネマティック映像モードになります。
**ファイルが無い場合は上質なグラデーション＋グレインのフォールバックが表示される**ため、
未設置のままでもレイアウトは崩れません（1本ずつ順次追加できます）。

- ファイル名は下表の通り**完全一致**させてください（HTML側の変更は不要です）

- 書き出し時は **`-movflags +faststart`**（ストリーミング最適化）を必ず付けてください
- 目安容量：**1本 3〜8MB**（合計40MB以内が理想）

## 推奨書き出し設定（ffmpeg）

```
ffmpeg -i INPUT.mov -an -vcodec libx264 -crf 24 -preset slow -pix_fmt yuv420p -movflags +faststart OUTPUT.mp4
```

- `-an` … 音声削除
- `-crf 24` … 画質と容量のバランス（20で高画質・28で軽量）
- `-movflags +faststart` … 先頭再生の高速化（必須）
